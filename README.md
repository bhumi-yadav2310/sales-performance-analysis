# Sales-performance-analysis using python and numpy
##Project Objective
This project analyzes sales data for multiple products over several months to provide actionable insights for business decisions . It identifies top-performing and underperforming products,evaluates month-wise revenue , calculates product contribution,assigns performance labels and ranks products based on total sales
##Tools and Technologies Used:
-Python3
-NumPy
##Features:
-Total and average sales
- Best and Worst performing products
- Monthwise Revenue Analysis
- Product Contribution
- Performance labels'
- Product Ranking
- Business insights ready
##Dataset
Sales data is represented as a 2D NumPy array:
  Rows: Products
  Columns:Months
